🛡️ Password Security Tips

Use Long Passwords

Longer passwords are generally harder for attackers to guess. Prefer 12–16+ characters.

Use Unique Passwords

Don't reuse the same password across multiple websites.

Use a Password Manager

A password manager can create and remember unique passwords for different accounts.

Never Share Passwords

Legitimate services should not ask you to send your password through email or chat.
